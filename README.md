# فریمان

فرم چندمرحله‌ای فارسی برای جمع‌آوری **نیازمندی‌های کسی که می‌خواهد فروشگاه اینترنتی ورزشی بسازد** — نه فرم خرید مشتری. صاحب کسب‌وکار می‌گوید سایت، شبیه فروشگاه‌های بزرگ پوشاک و لوازم ورزشی، چه امکاناتی باید داشته باشد: کاتالوگ، تجربه خریدار، پرداخت، ارسال و پنل مدیریت.

## چه چیزی جمع می‌شود؟

- معرفی فروشگاه ورزشی و وضعیت سایت فعلی
- برندها و دسته‌های کالا (پوشاک، کفش، تجهیزات)
- امکاناتی که خریدار فروشگاه باید ببیند (راهنمای سایز، فیلتر، نظر، چت)
- درگاه پرداخت، ارسال، تعویض سایز و گارانتی
- ابزارهای پنل مدیریت برای خود فروشگاه
- سبک طراحی و سایت‌های مرجع

**شماره موبایل خریدار یا جزئیات یک سفارش گرفته نمی‌شود.**

## اجرا

```bash
cp .env.example .env
npm install
npm run setup
npm run dev
```

سایت روی `http://localhost:3000` باز می‌شود.

### حساب مدیر

- ایمیل: `admin@fariman.ir`
- رمز: `Admin1234!`

صاحب فروشگاه با ایمیل و رمز ثبت‌نام می‌کند (بدون تأیید ایمیل)، فرم را مرحله‌به‌مرحله پر می‌کند و پیش‌نویس ذخیره می‌شود. بعد از «ثبت نهایی» دیگر نمی‌تواند فرم را دوباره ویرایش کند.
